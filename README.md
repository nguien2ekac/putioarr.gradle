# jankenpo em JavaScript
Jogo simples de pedra, papel e tesoura escrito em JavaScript

## Preparação
A ideia é rodar o jogo com o interpretador do Node.JS, então instale o Node.JS primeiro, na versão que preferir. Como o projeto não usa bibliotecas externas, não é necessário rodar o instalador de pacotes.


### Observação

Os nomes de arquivo e pasta foram mantidos como no projeto original.

## Observação
Para ler entrada do teclado não é preciso instalar pacote adicional.

## Demonstração

Gravação do jogo em uso disponível em vídeo.

## Execução

Basta chamar o interpretador apontando para o arquivo de entrada.
